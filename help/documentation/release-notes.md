# 릴리스 정보

이 페이지에서는 Adobe Experience Manager Sites Optimizer의 최신 업데이트, 새로운 기능 및 개선 사항을 문서화합니다.

**(조기 액세스)**(으)로 표시된 기능은 요청 시 사용할 수 있습니다. 귀하의 계정 팀이나 고객 성공 엔지니어에게 문의하여 귀사에서 사용할 수 있도록 설정하십시오.

## 2026년 8월 20~27일

### 새로운 기능

- **경고 보기** — 자동으로 감지된 사이트 상태 인시던트에 대한 90일 타임라인을 검토하고, 변경 내용을 배포 및 콘텐츠 업데이트와 상호 연관시키고, 영향을 받는 페이지 및 성능 지표를 한 곳에서 검사합니다.
- **보고서 및 Wins** - 보고서 섹션을 사용하여 최적화 작업의 영향을 알리는 데 도움이 되는 최적화 기록, 성능 트렌드 및 Wins 전후의 Wins를 검토합니다.
- **새로운 기능 및 도움말 센터** - 최근에 릴리스된 기능을 살펴보고 제품 설명서를 연 다음 인앱 도움말 센터에서 직접 릴리스 정보에 액세스합니다.
- **Google 광고 연결(조기 액세스)** — Google 광고 계정을 연결하여 유료 트래픽 성능 데이터를 Sites Optimizer 기회 및 권장 사항으로 가져옵니다.

### 개선 사항

- **영업 기회 목록 컨트롤** - URL, 별색 상태, 우선 순위 또는 최신성을 기준으로 영업 기회를 필터링 및 정렬하고, 공유를 위해 URL에 보기를 저장하고, 제안 데이터를 CSV로 내보냅니다.
- **제안 워크플로우 컨트롤** — 배포 전에 AI에서 생성한 제안을 편집하고, 개별 제안을 무시하고, 전체 기회를 건너뛰고, 건너뛰었던 기회가 다시 관련성이 생기면 이를 복원합니다.
- **배포 기록** — 날짜별 배포 기록을 검토하고, 자동 배포와 수동으로 배포된 것으로 표시된 변경 내용을 구분하고, 코드 기반 수정 사항에 대한 가져오기 요청 링크를 따릅니다.
- **브랜드 및 Slack 통합** — 브랜드 내 콘텐츠 생성을 위한 Adobe GenStudio 브랜드를 선택하고 구성된 Slack 채널과 관련 최적화 업데이트를 공유합니다.

## 2026년 8월 6~19일

### 새로운 기능

- **AEM Sites 페이지 편집기의 Preflight** — 작성 환경에서 AEM 2026.7.0 이상을 실행하는 경우 페이지 편집기 도구 모음에서 직접 Preflight를 열어 작성 워크플로에서 나가지 않고 현재 페이지를 분석할 수 있습니다.
- **Preflight 내보내기 옵션** - Preflight 결과를 CSV 또는 PDF으로 내보내고, 전달된 실행 메타데이터 및 감사를 포함하는 옵션을 통해 결과를 보다 쉽게 공유하고 준비 상태를 추적할 수 있습니다.

### 개선 사항

- **Preflight 세션 세부 정보** — 이전 감사 세션을 계속하면 Preflight는 실행이 수행된 시기를 보여주며 읽을 수 있는 텍스트나 CSS 선택기를 표시하여 영향을 받는 요소를 보다 쉽게 식별할 수 있도록 합니다.

## 2026년 7월 1~19일

### 새로운 기능

- **권한 관리(조기 액세스)** — 사용자 관리 기능을 가진 사용자는 이제 새 권한 탭에서 사이트 액세스를 제어할 수 있습니다. 이름 또는 전자 메일로 사람을 검색하고 특정 기능을 부여하거나 취소할 수 있습니다. 사용자가 수행할 수 없는 작업은 액세스 요청 방법을 설명하는 도구 설명이 있는 상태로 비활성화됩니다.
- **배포 상태 배지** — 수동으로 배포됨으로 표시된 수정 사항이 이제 배포됨 보기에 고유한 &quot;배포됨으로 표시&quot; 배지가 표시되므로 자동 배포와 별도로 수동 업데이트를 쉽게 구별할 수 있습니다.

### 개선 사항

- **GitHub(Cloud Manager)에 대한 자동 수정** - Core Web Vitals, 보안 및 양식 액세스 가능성과 같은 기회에 대한 코드 패치 자동 수정은 이제 GitHub에서 호스팅되는 고유한 Git 저장소를 Cloud Manager에 가져오기 요청을 발생시켜 GitLab, Bitbucket 및 Azure DevOps에 대한 기존 지원을 일치시킬 수 있습니다. 새 설정 토글을 사용하여 사이트에 대한 1회 설정 확인을 제어할 수 있습니다.
- **분기를 통한 자동 수정(Cloud Manager Standard)** — 이제 사이트에 대해 활성화된 경우 분기를 통한 자동 수정을 Cloud Manager 표준 저장소에서 사용할 수 있습니다.
- **배포된 보기: 수행한 사람** - 이제 배포된 보기는 새 &quot;수행한 사람&quot; 및 &quot;최근 업데이트된 상태&quot; 열을 통해 각 수정 사항을 배포된 것으로 표시한 사람과 해당 상태가 마지막으로 업데이트된 시기를 표시합니다.
- **Google 광고 연결 끊기 피드백** — 이제 [설정]에서 Google 광고 계정의 연결을 끊으면 &quot;연결 끊기...&quot; 상태가 표시되고 연결 끊기가 실패하면 다시 시도할 수 있습니다.

### 버그 수정

- 이제 ARIA 레이블 수정 기회에 수정 사항이 여러 페이지에 걸쳐 있을 때 세부 정보 대화 상자에 올바른 페이지 URL이 표시됩니다.
- 이제 건너뛰기 대화 상자의 정보 메시지가 올바르게 정렬된 한국어, 중국어 간체 및 중국어 번체로 올바르게 표시됩니다.
- 대체 텍스트 및 잘못되거나 누락된 메타데이터에 대한 관련 페이지 대화 상자가 이제 안정적으로 로드되며, 잘못되거나 누락된 메타데이터 배포 보기 및 메타 태그 수정 사항이 이제 최신 제안 형식으로 올바르게 작동합니다.

## 2026년 5월 11~22일

### 새로운 기능

- **사이트 경고 보고서(조기 액세스)** — 새로운 90일 사이트 경고 보고서는 색상으로 구분된 일일 블록을 사용하여 높은 경고 기간을 강조 표시하여 시간에 따른 트렌드를 빠르게 식별하고 조사할 수 있도록 사이트 상태에 대한 분기별 보기를 제공합니다.
- **운영 원격 분석 온보딩** — 아직 운영 원격 분석 데이터에 연결되지 않은 사이트에서는 이제 홈 페이지의 영구 배너와 설정을 완료하는 안내 온보딩 대화 상자를 받아 실제 사용자의 성능을 완전히 확인할 수 있습니다.
- **대체 텍스트: 다중 사이트 관리자 인식** — 이제 AEM 다중 사이트 관리자 또는 언어 사본을 사용하는 사이트에 대한 대체 텍스트 수정 사항을 생성할 때 Sites Optimizer은 수정 사항을 제안하기 전에 각 언어 변형에 안전하게 적용할 수 있는지 여부를 확인합니다.

### 개선 사항

- **대체 텍스트 정확도** — 대체 텍스트 제안은 이제 가장 최근 감사 신호에서 가져오며, 다시 감지된 문제는 전체 그림을 위해 현재 문제 및 배포됨 탭에 모두 표시됩니다.

### 버그 수정

- 이제 배포 버튼 상태에 수정 사항을 실제로 배포할 수 있는지 여부가 올바르게 반영됩니다.
- 이제 어두운 테마가 페이지 새로 고침 시 올바르게 적용됩니다.
- 보고서에는 사용자의 로케일로 날짜가 표시됩니다.
- 이제 언어 및 번호/날짜 형식에 대한 지역 환경 설정을 독립적으로 구성할 수 있습니다.
- 이제 깨진 이미지 대체 텍스트에 화면 판독기에 액세스할 수 있습니다.

## 2026년 4월 21일~5월 10일

### 새로운 기능

- **사이트 온보딩된 상태가 없음** — 아직 사이트를 추가하지 않은 고객은 홈 페이지에서 빠르게 시작할 수 있도록 명확하고 실행 가능한 프롬프트를 볼 수 있습니다.
- **도움말 센터의 설명서** - 이제 Experience League의 AEM Sites Optimizer 설명서는 제품을 종료하지 않고 인앱 도움말 센터에서 바로 액세스할 수 있습니다.

### 버그 수정

- 활성 제안 사항이 없는 사이트에 작업 필요 대화 상자가 올바르게 표시됩니다.
- 건너뛴 제안이 예상대로 무시됨 탭에 표시됩니다.
- 유료 트래픽 선택기 드롭다운에서 더 이상 번역된 텍스트를 자르지 않습니다.
- 이제 사이트 맵 페이지 선택기의 크기가 올바르게 조정되었습니다.

## 2026년 3월 13일~4월 20일

### 새로운 기능

- **평가판 온보딩** — 이제 새로운 평가판 사용자는 안내가 있는 설정 흐름을 경험합니다. 도메인을 입력하고 분석을 기다린 다음 첫 번째 기회를 탐색하십시오. 시작하는 데 필요한 구성이 없습니다.
- **평가판 기회 페이지** - 평가판 사용자는 3개의 제안이 잠금 해제되고 업그레이드 프롬프트가 있는 잠긴 미리 보기에 표시되는 기회를 검색, 정렬 및 필터링할 수 있습니다.
- **월별 최적화 진행 상황** - 홈 페이지의 진행률 표시줄은 이번 달에 수행한 최적화 작업의 수를 추적하므로 사이트 상태 목표를 최상으로 유지할 수 있습니다.
- **감사 대상 URL(조기 액세스)** — 이제 [설정]에서 최대 100개의 사용자 지정 URL을 지정하여 해당 페이지가 항상 감사에 포함되도록 할 수 있습니다.
- **배달 유형 구성** — 이제 설정을 사용하여 사이트의 배달 유형(Edge Delivery Services, AEM Cloud Service 또는 AEM Managed Services)을 지정하고 콘텐츠 공급자를 연결할 수 있습니다.
- **Core Web Vitals 다시 디자인** — Core Web Vitals 영업 기회가 Jira 연결, CSV 다운로드 및 배치 작업에 대한 다중 선택 지원을 통해 다시 디자인되었습니다.
- **끊어진 백링크 통합 테이블** - 이제 모든 원본에서 끊어진 백링크가 CDN 리디렉션 규칙을 직접 내보낼 수 있는 기능을 사용하여 단일 통합 테이블에 표시됩니다.
- **접힌 부분 위에 CTA 없음: 작성자에게 배포** - 접힌 부분 위에 CTA 없음 기회에 대한 수정 사항을 이제 AEM 작성자에게 직접 배포할 수 있습니다.
- **Forms 자동 수정 배포** - 이제 Forms 영업 기회 수정 사항을 AEM 작성자에게 직접 배포할 수 있습니다.
- **AEM 다중 사이트 관리자 지원** - 사이트의 여러 언어 사본에 영향을 주는 기회에 따라 &quot;수정된 위치&quot; 열을 사용하여 수정 사항이 적용된 루트 사이트가 표시됩니다.
- **실패한 수정 사항 건너뛰기** - 이제 배포가 실패한 개별 수정 사항을 건너뛰고 워크플로우의 차단을 해제할 수 있습니다.
- **AEM 편집기에서 열기** — 이제 빠른 인라인 편집을 위해 AEM의 시각적 편집기에서 영향을 받는 페이지를 열 수 있는 직접 링크가 영업 기회 제안에 포함됩니다.

## 2026년 2월 28일~3월 13일

### 새로운 기능

- **광고 의도 불일치 기회** — 새 기회 유형은 전환되지 않고 바운스 비율, 클릭당 비용 및 트래픽 지표를 나타내는 유료 트래픽 랜딩 페이지를 식별하여 랜딩 페이지 개선 사항의 우선 순위를 지정하는 데 도움이 됩니다.
- **상위 CTA 없음** - 이제 이 영업 기회는 고유한 세부 정보 페이지와 필터링이 포함된 전용 1등급 유형으로, 전환 개선 사항을 추적하고 우선 순위를 지정하는 데 더 편리해졌습니다.
- **사이트 맵 URL 제안** — 이제 사이트 맵 영업 기회에서 404 오류를 반환하는 페이지에 대한 대체 URL을 제안하여 끊어진 사이트 맵 항목을 보다 쉽게 수정할 수 있습니다.
- **끊어진 백링크 다시 디자인** — 끊어진 백링크 세부 정보 페이지가 명확성과 유용성을 개선하도록 다시 디자인되었습니다.

### 개선 사항

- **상위 유기 검색 페이지 V2** — 이제 유기 트래픽 데이터가 30일 Ahrefs 데이터 세트에서 소싱되므로 더 포괄적이고 실행 가능한 검색 성능 인사이트를 제공합니다.
- **보안 취약성: 종속성 트리** — 이제 보안 취약성 세부 정보에 종속성 트리 시각화가 포함되어 있으므로 프로젝트 전체에서 취약성이 미치는 전체 영향을 이해할 수 있습니다.

## 2026년 2월 14~27일

### 새로운 기능

- **상위 유기 검색 페이지** — 이제 사이트 상태 모니터에 사이트의 상위 유기 트래픽 페이지를 표시하는 전용 탭이 포함되어 있어 가장 많은 검색 트래픽을 유도하는 콘텐츠를 확인할 수 있습니다.
- **대체 텍스트 자동 수정 V2** — 대체 텍스트 수정 기능을 배포하기 전에 사전 실행 &quot;수정 기능 확인&quot; 평가를 실행하여 수정 사항이 콘텐츠에 성공적으로 적용되었는지 확인할 수 있습니다.
- **대체 텍스트에 대한 배포된 보기** — 이제 대체 텍스트 수정 사항이 배포된 탭에 표시되어 현재 해결되지 않은 문제와 함께 접근성 향상에 대한 전체 기록을 제공합니다.
- **외부 조직 배포 게이트** — 외부에서 관리되는 사이트에 수정 사항을 배포할 때 이제 실수로 변경되는 것을 방지하기 위해 명시적인 확인 단계가 필요합니다.

### 개선 사항
