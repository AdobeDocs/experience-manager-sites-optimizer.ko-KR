# Preflight 감사 결과

감사가 완료되면 Preflight는 감사 결과를 기회로 표시합니다. 각 기회는 유형별로 구성되며 페이지를 강화하고 최적화하는 데 도움이 되는 권장 사항을 포함하고 있습니다. 기회 내에서 개별 문제는 검토하거나 수정할 특정 항목을 식별합니다.

AEM Preflight 대화 상자의 맨 위에는 전체 감사 결과를 반영하는 사용자 진행률 표시줄이 있습니다. 이 표시줄은 문제없이 통과한 기회의 백분율과 모든 기회에서 발견된 총 문제 수를 보여 줍니다. 사용자 진행률 표시줄을 통해 작성자는 전체 페이지 상태를 한눈에 파악할 수 있습니다.

![AEM Preflight 대화 상자의 사용자 진행률 표시줄 및 감사 기회](./assets/overview/hero.png){align="center"}

이 표시줄은 색상으로 구분됩니다.

* 완료된 기회가 **1/3 미만**&#x200B;일 경우 빨간색 표시
* 완료된 기회가 **1/3에서 2/3 사이**&#x200B;일 경우 주황색 표시
* 완료된 기회가 **2/3를 초과**&#x200B;할 경우 녹색 표시
* 감사가 **여전히 실행 중**&#x200B;일 경우 파란색 표시

[사용 가능한 기회 유형의 전체 목록과 해당 기회 유형을 해결하는 방법](./overview.md#preflight-opportunities)을 참조하십시오.

## 기회 강조 표시

감사가 완료된 후 페이지에서 기회를 직접 강조 표시하여 기회를 빠르게 찾고 이해할 수 있습니다.

>[!VIDEO](https://video.tv.adobe.com/v/3483419/?captions=kor&learn=on&enablevpops)

Preflight는 각 기회를 컨텍스트에서 강조 표시하여 패널에 표시된 결과를 콘텐츠의 정확한 위치에 연결합니다. 그러면 페이지를 수동으로 검색하지 않고도 기회를 훨씬 더 쉽게 검토하고 해결할 수 있습니다.

1. 감사할 페이지의 컨텍스트에서 Preflight 패널을 열고 감사를 실행합니다.
1. Preflight 패널 목록에서 특정 기회를 선택합니다.
1. 미리 보기가 관련 영역으로 자동 스크롤되고 해당 요소를 강조 표시하므로 컨텍스트에서 기회를 쉽게 식별하고 최적화할 수 있습니다.
