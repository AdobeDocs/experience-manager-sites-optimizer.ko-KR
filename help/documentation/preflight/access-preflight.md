# Preflight 액세스

Preflight는 범용 편집기, 문서 기반 작성 및 AEM Sites 페이지 편집기를 비롯한 AEM Sites 작성 환경에서 사용할 수 있습니다. [프리플라이트]는 작성 중인 페이지에서 패널로 열립니다. 패널에서 해당 페이지에 대해 [감사를 실행](./audits.md)하고 Preflight [모든 기회를 표시](./audit-results.md)하여 게시하기 전에 페이지를 향상시킵니다.

* **범용 편집기** – Preflight 확장 기능이 **사이드 레일**&#x200B;에 표시됩니다. 이 옵션을 선택하여 [프리플라이트] 패널을 엽니다.
* **문서 기반 작성** - 미리 본 페이지 콘텐츠의 Sidekick 또는 북마클릿에서 [미리 보기] 패널을 엽니다.
* **AEM Sites 페이지 편집기** - AEM 2026.7.0(릴리스 27083) 이상의 경우 편집기 도구 모음의 **Preflight** 아이콘을 선택하여 [Preflight] 패널을 엽니다. 이전 릴리스에서는 대신 브라우저의 Preflight 북마클릿을 사용하십시오.

패널이 열린 후 **페이지 분석**&#x200B;을 선택하여 현재 페이지에 대한 감사를 시작합니다.

설정 지침은 [Preflight 설정](./setup.md)을 참조하십시오.
