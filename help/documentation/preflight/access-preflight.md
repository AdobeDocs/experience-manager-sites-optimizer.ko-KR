# Preflight 액세스

Preflight는 범용 편집기, 문서 기반 작성, AEM Sites 페이지 편집기를 포함한 AEM Sites의 작성 환경에서 사용할 수 있습니다. Preflight는 작성 중인 페이지에서 열리는 패널로, 해당 페이지에 대한 [감사를 실행](./audits.md)하고 페이지 게시 전에 발견한 개선할 수 있는 [모든 기회를 표시](./audit-results.md)합니다.

* **범용 편집기** – Preflight 확장 기능이 **사이드 레일**&#x200B;에 표시됩니다. 해당 기능을 선택하여 현재 페이지에 대한 감사를 시작합니다.
* **문서 기반 작성** – Sidekick 또는 북마클릿을 통해 표시되며 미리 본 페이지 콘텐츠의 Preflight 도구를 실행하여 기회 목록을 확인합니다.
* **AEM Sites 페이지 편집기** – 브라우저에서 Preflight 북마클릿을 사용하여 감사를 시작합니다.

설정 지침은 [Preflight 설정](./setup.md)을 참조하십시오.
