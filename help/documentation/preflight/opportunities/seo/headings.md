# 머리글 감사

**제목** 감사에서 페이지의 제목 구조를 검토합니다. 명확하고 순서가 지정된 제목 계층 구조를 통해 독자와 검색 엔진 모두 콘텐츠가 구성되는 방식을 이해할 수 있습니다. 감사는 수준을 건너뛰거나 잘못된 순서로 나타나는 제목과 같은 문제에 플래그를 지정합니다.

감사가 기회를 발견하면 각 감사에서 영향을 받는 헤딩을 식별하고 권장 변경 사항을 설명합니다. 영업 기회를 검토하고 해결하는 방법은 [Preflight에서 결과 감사](../../audit-results.md)를 참조하세요.
