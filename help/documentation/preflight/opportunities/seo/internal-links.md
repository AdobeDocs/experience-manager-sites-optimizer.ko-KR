# 내부 링크 감사

**내부 링크** 감사에서는 사용자의 사이트로 돌아가는 페이지의 링크를 검토합니다. 감사는 편집 중인 페이지의 각 내부 링크를 검사하고 방문자가 팔로우할 수 없는 곳에서 끊겼거나 안전하지 않거나 지정된 링크에 플래그를 지정합니다.

## 왜 중요한가

끊어진 링크는 리더의 막다른 길이며 검색 엔진 내부 크롤링이 검색 엔진에 값을 전달하지 않는 페이지입니다. 내부 링크는 실수로 끊기 가장 쉬운 종류이기도 합니다. 즉, 페이지가 이동되거나 이름이 바뀌고, 페이지에 연결된 모든 링크가 자동으로 작동하지 않습니다. 링크는 모두 자체 사이트에 있으므로 사용자가 직접 수정할 수 있는 링크이기도 합니다.

## 감사 확인 사항

감사는 다음 문제 중 하나가 있는 각 내부 링크에 대한 기회를 보고합니다.

* **끊어진 링크:** 링크가 오류를 반환합니다(예: `Status 404` 또는 `Status 500`). 리디렉션 후 오류에 도달하는 링크도 같은 방식으로 보고됩니다.
* **비보안 링크:** 링크는 `https://` 대신 `http://`을(를) 사용합니다. 동일한 URL의 보안 버전이 작동하면 Preflight가 제안으로 제공합니다.
* **편집기 URL:** 링크가 콘텐츠 페이지 대신 AEM 편집기 URL을 가리킵니다. 링크를 작성하는 동안에는 링크가 자동으로 작동하므로 누락되기 쉽지만, 모든 방문자가 작성 인터페이스에 도착합니다. Preflight는 콘텐츠 URL을 제안합니다.
* **누락된 조각:** 대상 페이지에 없는 앵커(예: `#pricing`)의 링크 지점. 페이지가 여전히 열리지만 독자가 의도한 섹션 대신 맨 위에 도달하므로 링크가 끊어진 것보다 더 낮은 영향에서 보고됩니다. 페이지의 동일한 앵커가 서로 다르게 대문자로 표시되는 경우 Preflight에서 수정된 앵커를 제안합니다. 대상 페이지 자체가 끊어진 경우 대신 **끊어진 링크**&#x200B;로 보고됩니다.
* **확인되지 않은 링크:** 검사 시간이 초과되었거나 네트워크 오류가 발생했습니다. Preflight는 링크의 작동 여부를 알 수 없으므로 링크가 손상되었다고 보고하지 않고 직접 링크를 확인하라는 메시지를 표시합니다.

정상적으로 확인되는 링크는 도중에 여러 리디렉션이 있더라도 플래그가 지정되지 않습니다. 는 더 이상 내부 링크가 아니므로 다른 사이트로 리디렉션하는 링크도 아닙니다.

## 링크 확인 방법

감사는 작성 세션의 링크를 확인하므로 보기 위해 로그인한 방식으로 링크가 표시됩니다. 작성자 인스턴스에만 존재하는 페이지는 손상된 것으로 보이지 않고 올바르게 확인됩니다.

편집기가 페이지에서 클릭 가능한 링크를 제거하더라도 AEM의 링크 검사기가 이미 유효하지 않은 것으로 표시된 링크는 감사에 포함됩니다. 그런 다음 트러스트에서 가져오지 않고 다시 확인되므로 작업 시작 이후 링크는 보고되지 않습니다.

링크가 나타나는 모든 위치에 대해 하나의 기회가 보고되므로, 세 개의 지점에 사용된 잘못된 링크는 세 개의 인스턴스를 수정하여 페이지에서 각 지점의 강조 표시를 합니다. 이러한 지점 중 하나에 둘 이상의 문제가 있는 경우 Preflight는 하나의 카드에 두 지점을 함께 표시합니다.

## 알려진 제한 사항

감사는 AEM Sites 페이지 편집기, Adobe Managed Services(AMS) 및 Sidekick을 통한 문서 기반 작성에서 실행됩니다. 현재 범용 편집기에서 사용할 수 없습니다.

## 해결 방법

감사에서 기회가 발견되면 각 단계에서 문제 및 권장 변경 사항을 설명하고 관련 링크를 파악합니다. **페이지에서 강조 표시**&#x200B;를 사용하여 콘텐츠의 링크로 이동하고, **현재 URL** 섹션을 사용하여 URL을 복사하거나 새 탭에서 열어 문제를 직접 확인할 수 있습니다. 영업 기회를 검토하고 해결하는 방법은 [Preflight에서 결과 감사](../../audit-results.md)를 참조하세요.
