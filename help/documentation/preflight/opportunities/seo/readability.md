# 가독성 감사

**가독성** 감사에서는 페이지 콘텐츠를 얼마나 쉽게 읽을 수 있는지 검토합니다. 명확하고 구조가 잘 짜인 콘텐츠는 독자의 참여를 유도하며 더 많은 대상자가 메시지를 이해하는 데 도움이 됩니다. 감사는 콘텐츠를 평가하고 개선을 위해 실행 가능한 권장 사항을 제공합니다.

가독성 감사는 다음과 같은 여러 언어의 콘텐츠를 지원합니다.

* 영어
* 프랑스어
* 스페인어
* 이탈리아어
* 독일어
* 네덜란드어

감사에서 기회가 발견되면, 각 기회는 문제와 권장 변경 사항을 설명합니다. 영업 기회를 검토하고 해결하는 방법은 [Preflight에서 결과 감사](../../audit-results.md)를 참조하세요.
