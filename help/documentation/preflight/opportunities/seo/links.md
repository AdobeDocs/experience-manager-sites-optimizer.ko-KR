# 링크 감사

**링크** 감사에서 페이지의 링크를 검토합니다. 끊기거나 안전하지 않은 링크가 사용자 경험을 손상시켜 크롤링을 효과적으로 검색하고 사이트를 줄일 수 있습니다. 감사 플래그는 게시하기 전에 수정할 수 있도록 주의가 필요한 링크에 플래그를 지정합니다.

감사가 기회를 발견하면 각 감사에서 영향을 받는 링크를 식별하고 권장 변경 사항을 설명합니다. 영업 기회를 검토하고 해결하는 방법은 [Preflight에서 결과 감사](../../audit-results.md)를 참조하세요.
