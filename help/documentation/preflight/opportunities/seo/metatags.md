# 메타태그 감사

**메타데이터** 감사에서는 페이지 제목, 메타데이터 설명 및 기본(H1) 머리글을 검토합니다. 누락되었거나 비어 있거나 권장 길이를 벗어난 모든 페이지에 플래그를 지정하고 H1 머리글이 두 개 이상인 페이지에 플래그를 지정합니다.

## 왜 중요한가

페이지 제목과 메타 설명은 일반적으로 사람들이 검색 결과에서 페이지에 대해 클릭할 수 있는 헤드라인으로 제목이 표시되고 그 아래 요약으로 설명이 표시됩니다. 누락되거나 크기가 잘못된 제목 또는 설명은 검색 엔진이 페이지에서 선택하는 텍스트로 대체되거나 잘릴 수 있습니다. H1 머리글은 독자와 검색 엔진에 페이지의 주요 내용을 알려주므로 페이지는 하나의 명확한 H1을 가져야 합니다.

## 감사 확인 사항

감사는 다음 각 문제에 대한 기회를 보고합니다.

* **페이지 제목:**&#x200B;이(가) 없거나, 비어 있거나, 너무 짧거나, 이상적인 길이보다 깁니다.
* **Meta 설명:**&#x200B;이(가) 없거나, 비어 있거나, 너무 짧거나, 이상적인 길이보다 깁니다.
* **H1 제목:**&#x200B;이(가) 없거나, 비어 있거나, 이상적인 길이보다 길거나, 페이지에 H1이 두 개 이상 있습니다.

이상적인 길이에 비해 몇 글자 수가 **이상적인 길이보다** 높게 보고되었으며, 감사 최대값보다 **너무 깁니다**. Preflight에는 페이지 제목에 대해 너무 긴 임계값이 없습니다.

| 태그 | 이상적인 길이 | 이상 길이 | 너무 김 |
|---|---|---|---|
| 페이지 제목 | 40~60자 | 60자 이상 | - |
| Meta 설명 | 140~160자 | 161~175자 | 175자를 초과하는 것 |
| H1 제목 | 최대 70자 | 71~75자 | 75자 초과 |

이러한 범위는 검색 엔진 요구 사항이 아닌 권장 지침입니다. Preflight는 이 필드를 사용하여 기회를 보고할 시기를 결정합니다.

## 값을 읽는 방법

감사가 편집 중인 페이지를 읽습니다. `<title>` 요소의 텍스트, `<meta name="description">` 태그의 콘텐츠, 첫 번째 `<h1>` 요소의 보이는 텍스트(그 안에 굵은 기울임꼴 텍스트 포함).

태그가 페이지에 없으면 **누락**&#x200B;되고, 태그가 있지만 표시되는 텍스트가 없으면 **비어 있음**&#x200B;됩니다. 길이는 공백 및 구두점을 포함하여 모든 문자를 계산합니다. 첫 번째 H1만 길이를 확인합니다. 페이지에 H1이 두 개 이상 있으면 각 H1이 별도의 인스턴스로 나열되므로 추가 제목을 찾아 변경할 수 있습니다.

## 제안 사항

모든 기회에는 태그에 대한 이상적인 길이 또는 페이지의 H1 하나와 같은 권장 사항이 포함됩니다.

페이지 제목, 메타 설명 및 H1 기회에는 페이지의 자체 콘텐츠에서 작성된 AI가 생성한 제안도 포함될 수 있습니다. 이상적인 길이에 맞는 제안만 표시됩니다. 모든 제안을 사용하기 전에 검토하고 편집하십시오.

H1 기회에 AI 제안이 없는 경우, 해당 제안은 머리글을 줄이거나 추가 H1 머리글을 H2로 변경하는 것과 같이 대신 고정 조언입니다. 페이지 제목 또는 메타 설명 기회에 AI 제안이 없으면 Preflight에서 제안 사항을 사용할 수 없음을 보여 줍니다.

## 플래그가 지정된 값이 올바르게 표시되는 경우

Edge Delivery Services 페이지에서는 설정하지 않은 페이지 제목이나 메타 설명이 페이지의 첫 번째 머리글과 첫 번째 단락에서 자동으로 채워집니다. 종종 이상적인 길이보다 짧아 페이지에 플래그가 지정됩니다. 페이지 메타데이터에서 고유한 제목 및 설명을 설정하면 이 문제가 해결됩니다.

## 알려진 제한 사항

* **다른 헤드 태그는 확인되지 않습니다.**(예: 소셜 공유를 위한 그래프 열기 태그 또는 로봇 태그)
* **길이는 문자로 계산됨:** 검색 엔진은 화면에 차지하는 공간을 기준으로 제목과 설명을 줄이므로 검색 결과에서 이상적인 길이 내의 값을 계속 줄일 수 있습니다.
* **단어 사이에 공백 없는 언어:** 중국어, 일본어 또는 한국어 등의 언어로 된 페이지에서 읽을 수 있는 값에 여전히 플래그가 지정될 수 있으며 AI 제안 사항이 이상적인 길이를 벗어날 수 있습니다.

## 해결 방법

각 영업 기회는 문제 및 권장 변경 사항에 대해 설명하고 페이지 제목 또는 메타 설명의 현재 값을 표시합니다.

* **페이지 제목과 메타 설명:** 사이트에서 페이지 제목을 설정하는 위치(예: AEM Sites의 페이지 속성 또는 Edge Delivery Services의 페이지 메타데이터)에서 업데이트합니다. 이러한 태그는 페이지 머리글에 있으므로 **페이지에서 강조 표시**&#x200B;를 사용할 수 없습니다.
* **H1 제목:** **페이지에서 강조 표시**&#x200B;를 사용하여 콘텐츠에서 제목을 찾습니다. Edge Delivery Services, AEM Sites 페이지 편집기 및 Adobe Managed Services(AMS)에서 Preflight는 제목으로 스크롤하고 윤곽을 표시합니다. 페이지 편집기와 AMS에는 **편집 모드**&#x200B;가 필요합니다. Preflight는 Universal Editor에서 제목 또는 제목이 들어 있는 가장 가까운 편집 가능한 블록을 선택합니다. 탐색 또는 바닥글의 머리글이 표시되지만 선택할 수 없습니다. 자세한 내용은 [페이지에서 강조 표시](../../audit-results.md#highlight-on-page)를 참조하십시오.

영업 기회를 검토하고 해결하는 방법은 [Preflight에서 결과 감사](../../audit-results.md)를 참조하세요.
