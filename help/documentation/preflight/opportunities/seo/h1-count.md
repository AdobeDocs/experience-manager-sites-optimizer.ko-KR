# H1 카운트 감사

**H1 count** 감사에서 페이지의 H1 머리글 수를 검토합니다. 일반적으로 페이지에는 컨텐츠를 요약하는 하나의 설명 H1이 있어야 합니다. 누락되거나 여러 개의 H1 제목이 있으면 페이지의 구조와 검색 엔진 최적화가 약화될 수 있습니다.

감사에서 기회가 발견되면, 각 기회는 문제와 권장 변경 사항을 설명합니다. 영업 기회를 검토하고 해결하는 방법은 [Preflight에서 결과 감사](../../audit-results.md)를 참조하세요.
