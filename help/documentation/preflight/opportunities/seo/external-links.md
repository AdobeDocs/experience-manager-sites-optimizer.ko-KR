# Preflight - 외부 링크 감사

**외부 링크** 감사에서는 다른 사이트를 가리키는 페이지의 링크를 검토합니다. 감사는 편집 중인 페이지에서 각 외부 링크를 확인하고 끊겼거나, 안전하지 않거나, 자동으로 확인할 수 없는 링크에 플래그를 지정합니다.

## 왜 중요한가

끊어진 외부 링크는 리더의 막다른 길이며 페이지가 잘 관리되지 않는다는 검색 엔진에 보내는 신호입니다. 외부 링크는 사용자가 가장 적게 제어할 수 있는 링크이기도 합니다. 다른 사이트는 언제든지 페이지를 이동하거나 이름을 변경하거나 제거할 수 있으며, 링크가 자동으로 작동하지 않습니다. 게시하기 전에 확인하면 링크가 처음 추가된 이후 오래된 링크가 포착됩니다.

## 감사 확인 사항

감사는 문제를 세 그룹으로 분류합니다.

* **끊김:** 링크가 현재 모든 방문자에 대해 실패하여 복구할 수 없습니다.
* **확인되지 않음:** 일부 방문자에 대해 링크가 실패하거나, 일시적으로 실패하거나, 확인할 수 없습니다.
* **우수 사례:** 링크가 작동하지만, 안전하지 않은 `http://` 링크와 같이 이러한 방식으로 작성해서는 안 됩니다.

감사는 다음 문제 중 하나가 있는 각 외부 링크에 대한 기회를 보고합니다.

* **끊어진 링크:** 링크를 여는 사람은 해당 링크가 작동하지 않습니다. Preflight는 다음과 같은 경우 링크가 끊어진 것으로 보고합니다.
  * 예를 들어 도메인이 더 이상 존재하지 않기 때문에 해당 사이트에 전혀 연결할 수 없습니다.
  * `Status 404` 또는 `Status 410`을(를) 반환합니다.
  * `Status 405`을(를) 반환합니다. 이것은 사이트가 일반 페이지 요청을 거부함을 의미합니다.
  * 루프로 리디렉션하거나 20회 이상 리디렉션합니다. 브라우저마다 동일한 제한을 사용하며 &quot;리디렉션이 너무 많습니다&quot; 오류가 표시됩니다.

  리디렉션이 보고된 후 이러한 오류 중 하나에 도달하는 링크도 동일한 방식으로 보고됩니다.
* **비보안 링크:** 링크가 `http://`을(를) 사용하고 Preflight에서 사이트가 응답하지 않는 경우를 포함하여 `https://`(으)로 리디렉션되는 것을 보지 못했습니다. `http://`(으)로 시작하지만 보안 `https://` 페이지로 리디렉션되는 링크에 플래그가 지정되지 않았습니다. `https://`을(를) 사용하도록 링크를 업데이트하십시오.
* **확인되지 않은 링크:** Preflight에서 링크가 작동하는지 확인할 수 없으므로 링크를 열고 직접 확인하라는 메시지가 표시됩니다. 영업 기회는 적용되는 사례를 설명합니다.
  * **로그인 필요:** 링크가 `Status 401`을(를) 반환합니다. 계정이 없는 방문자는 열 수 없으므로 의도한 것인지 확인하십시오.
  * **자동 검사 차단:** 링크가 `Status 403` 또는 `Status 429`을(를) 반환하거나 LinkedIn이 수행하는 것처럼 사이트에서 다른 방식으로 자동 요청을 차단합니다. 링크가 브라우저에서 열리는지 확인합니다.
  * **소셜 및 로그인 영역 사이트:** LinkedIn, Instagram, Facebook, X(Twitter), TikTok 및 Threads이 익명 요청에 잘못된 오류를 반환하므로, 이러한 사이트의 `Status 404`, `Status 410`, `Status 405` 또는 리디렉션 루프가 확인되지 않고 확인되지 않은 것으로 보고됩니다.
  * **서버 오류:** Preflight에서 다시 확인할 때 링크가 지속되는 서버 오류(`Status 5xx`)를 반환합니다. 보고하기 전에 프리플라이트 다시 시도 횟수 를 한 번 클릭합니다. 오류는 일시적일 수 있으므로 게시하기 전에 링크가 작동하는지 확인하십시오.
  * **사용할 수 없는 법적 이유:** 링크가 Preflight 확인 원본 지역에서 `Status 451`을(를) 반환합니다. 대상자에게 작동하는지 확인합니다.
  * **시간 내 응답 없음:** Preflight가 한 번 다시 시도된 후에도 사이트가 제시간에 응답하지 않았습니다. 사이트가 느려지거나 일시적으로 느려질 수 있습니다.

링크는 비보안 및 중단 또는 비보안 및 미확인 링크일 수 있으며, 이 경우 두 기회가 모두 보고됩니다. 리디렉션 체인이 20개 리디렉션 내에서 작업 페이지에 도달하면 리디렉션 체인에만 플래그가 지정되지 않습니다.

## 선택된 링크

페이지의 모든 외부 링크가 확인됩니다. 외부 링크는 편집할 페이지와 호스트가 다른 모든 링크입니다. 호스트는 도메인 이름과 `:8443` 같은 비표준 포트입니다. 하위 도메인은 다른 호스트로 계산되므로 `blog.example.com`과(와) `example.com`은(는) 모두 `www.example.com` 외부에 있습니다. 동일한 호스트에 대한 링크(예: 사용자 사이트에 대한 링크 `http://`개 포함)는 대신 [내부 링크](./internal-links.md) 감사에서 다룹니다. **사이트 탐색 링크 표시** 설정은 내부 링크 감사에만 적용되므로 사이트 탐색의 링크는 항상 포함됩니다. `mailto:`, `tel:` 및 `javascript:`과(와) 같은 링크는 무시됩니다.

각 링크는 페이지에 여러 번 나타나거나 `#pricing` 및 `#features`과(와) 같은 다른 앵커가 있는 경우에도 한 번 보고됩니다. Opportunity 는 링크가 처음 표시되는 위치를 강조 표시합니다.

편집기가 페이지에서 클릭 가능한 링크를 제거하더라도 AEM의 링크 검사기가 이미 유효하지 않은 것으로 표시된 링크는 감사에 포함됩니다. 이러한 속성은 트러스트에서 가져오지 않고 다시 확인되므로 작업 시작 이후 링크는 보고되지 않습니다.

## 결과 필터링

세부 정보 페이지에서 **인스턴스** 제목 옆의 필터를 사용하여 일부 기회만 표시합니다.

| 필터 | 표시된 영업 기회 |
|---|---|
| **모두**(기본값) | 모든 영업 기회 |
| **끊김** | 끊어진 링크 |
| **확인 필요** | 확인되지 않은 링크 및 비보안 링크 |

링크에 안전하지 않은 링크와 같이 두 개 이상의 기회가 있는 경우 각 기회가 자체 필터 아래에 표시됩니다. 자세한 내용은 [인스턴스 필터링](../../audit-results.md#filter-instances)을 참조하십시오.

## 알려진 제한 사항

* **개인 주소:** 인트라넷 사이트와 같은 개인 또는 내부 네트워크 주소에 대한 링크는 확인되지 않으며 보고되지 않습니다.
* **시간 제한:** 각 링크에는 자체 시간 제한이 있으므로 느린 사이트에서 다른 링크를 확인하지 못합니다. 페이지의 모든 링크는 결과를 얻습니다. 한 번 다시 시도해도 제시간에 응답하지 않는 링크는 끊어지지 않고 **확인되지 않은 링크**(으)로 보고됩니다.
* **제외된 도메인:** 사이트 구성에서 특정 도메인을 검사에서 제외할 수 있습니다. 제외된 도메인 또는 그 하위 도메인으로 연결되는 링크는 확인되지 않으며 보고되지 않습니다.
* **서버측 보기:** Preflight는 브라우저가 아닌 Adobe 서버의 외부 링크를 확인합니다. 위치, 로그인 또는 보트 감지에 따라 다르게 작동하는 사이트는 브라우저에 표시된 결과와 다른 결과를 반환할 수 있습니다. 이러한 링크는 일반적으로 끊어진 것이 아니라 **확인되지 않은 링크**(으)로 보고됩니다.

## 해결 방법

감사에서 기회가 발견되면 각 단계에서 문제 및 권장 변경 사항을 설명하고 관련 링크를 파악합니다. **페이지에서 강조 표시**&#x200B;를 사용하여 콘텐츠의 링크로 이동한 다음 새 탭에서 URL을 열어 문제를 직접 확인합니다. 그런 다음 영업 기회에 따라 행동합니다.

* **끊어진 링크:** 링크를 페이지의 새 위치로 업데이트하거나 바꾸거나 제거합니다. 리디렉션 루프는 다른 사이트의 소유자에게 문의하거나 다른 소스에 연결합니다.
* **비보안 링크:** 보안 버전이 작동하는지 확인한 후 `https://`을(를) 사용하도록 링크를 변경합니다.
* **확인되지 않은 링크:** 브라우저에서 링크를 열고 예상 페이지가 표시되는지 확인합니다. 로그인이 필요한 링크의 경우 독자에게 계정이 있어야 하는지 확인하십시오. 서버 오류의 경우 게시하기 전에 링크를 다시 확인하십시오. 링크가 작동하지 않으면 연결이 끊어진 것으로 처리합니다.

영업 기회를 검토하고 해결하는 방법은 [Preflight에서 결과 감사](../../audit-results.md)를 참조하세요.
