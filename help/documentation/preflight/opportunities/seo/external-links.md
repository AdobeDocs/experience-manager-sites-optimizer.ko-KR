# 외부 링크 감사

**외부 링크** 감사에서는 다른 사이트를 가리키는 페이지의 링크를 검토합니다. 감사는 편집 중인 페이지에서 각 외부 링크를 확인하고 끊겼거나 안전하지 않거나 자동으로 확인할 수 없는 링크에 플래그를 지정합니다.

## 왜 중요한가

끊어진 외부 링크는 리더의 막다른 길이며 페이지가 잘 관리되지 않는다는 검색 엔진에 보내는 신호입니다. 외부 링크는 사용자가 가장 적게 제어할 수 있는 링크이기도 합니다. 다른 사이트는 언제든지 페이지를 이동하거나 이름을 변경하거나 제거할 수 있으며, 링크가 자동으로 작동하지 않습니다. 게시하기 전에 확인하면 링크가 처음 추가된 이후 오래된 링크가 포착됩니다.

## 감사 확인 사항

감사는 다음 문제 중 하나가 있는 각 외부 링크에 대한 기회를 보고합니다.

* **끊어진 링크:** 링크가 `Status 404` 또는 `Status 410`을(를) 반환하거나 도메인이 더 이상 존재하지 않는 등의 이유로 해당 사이트에 전혀 연결할 수 없습니다. 리디렉션 후 오류에 도달하는 링크도 같은 방식으로 보고됩니다.
* **비보안 링크:** 링크는 `http://`을(를) 사용하며 사이트는 이를 `https://`(으)로 리디렉션하지 않습니다. `http://`(으)로 시작하지만 보안 `https://` 페이지로 리디렉션되는 링크에 플래그가 지정되지 않았습니다. `https://`을(를) 사용하도록 링크를 업데이트하십시오.
* **확인되지 않은 링크:** Preflight에서 링크가 작동하는지 확인할 수 없습니다. 예를 들어 사이트에 로그인이 필요하거나, 자동 검사를 차단하거나, 서버 오류를 계속 반환하거나, 제 시간에 응답하지 않거나, 너무 많이 리디렉션되기 때문입니다. LinkedIn 및 Instagram과 같은 일부 소셜 네트워크는 자동 검사에 누락된 것으로 존재하는 페이지를 보고하므로 해당 사이트에서 누락된 페이지 오류도 확인되지 않은 것으로 보고됩니다. 이러한 링크는 브라우저에서 작동할 가능성이 높으므로 Preflight는 연결이 끊어진 것으로 보고하지 않습니다. 대신 링크를 열고 직접 확인하라는 메시지가 표시됩니다.

링크는 비보안 및 중단 또는 비보안 및 미확인 링크일 수 있으며, 이 경우 두 기회가 모두 보고됩니다. 정상적으로 확인되는 링크는 도중에 리디렉션이 있더라도 플래그가 지정되지 않습니다.

## 선택된 링크

페이지의 모든 외부 링크가 확인됩니다. 외부 링크는 편집할 페이지와 호스트가 다른 모든 링크입니다. 호스트는 도메인 이름과 `:8443` 같은 비표준 포트입니다. 하위 도메인은 다른 호스트로 계산되므로 `blog.example.com`과(와) `example.com`은(는) 모두 `www.example.com` 외부에 있습니다. 동일한 호스트에 대한 링크(예: 사용자 사이트에 대한 링크 `http://`개 포함)는 대신 [내부 링크](./internal-links.md) 감사에서 다룹니다. **사이트 탐색 링크 표시** 설정은 내부 링크 감사에만 적용되므로 사이트 탐색의 링크는 항상 포함됩니다. `mailto:`, `tel:` 및 `javascript:`과(와) 같은 링크는 무시됩니다.

각 링크는 페이지에 여러 번 나타나거나 `#pricing` 및 `#features`과(와) 같은 다른 앵커가 있는 경우에도 한 번 보고됩니다. Opportunity 는 링크가 처음 표시되는 위치를 강조 표시합니다.

편집기가 페이지에서 클릭 가능한 링크를 제거하더라도 AEM의 링크 검사기가 이미 유효하지 않은 것으로 표시된 링크는 감사에 포함됩니다. 이러한 속성은 트러스트에서 가져오지 않고 다시 확인되므로 작업 시작 이후 링크는 보고되지 않습니다.

## 결과 필터링

세부 정보 페이지에서 **인스턴스** 제목 옆의 필터를 사용하여 일부 기회만 표시합니다.

| 필터 | 표시된 영업 기회 |
|---|---|
| **모두**(기본값) | 모든 영업 기회 |
| **끊김** | 끊어진 링크 |
| **확인 필요** | 확인되지 않은 링크 및 비보안 링크 |

링크에 안전하지 않은 링크와 같이 두 개 이상의 기회가 있는 경우 각 기회가 자체 필터 아래에 표시됩니다. 자세한 내용은 [인스턴스 필터링](../../audit-results.md#filter-instances)을 참조하십시오.

## 알려진 제한 사항

* **개인 주소:** 인트라넷 사이트와 같은 개인 또는 내부 네트워크 주소에 대한 링크는 확인되지 않으며 보고되지 않습니다.
* **서버측 보기:** Preflight는 브라우저가 아닌 Adobe 서버의 외부 링크를 확인합니다. 위치, 로그인 또는 보트 감지에 따라 다르게 작동하는 사이트는 브라우저에 표시된 결과와 다른 결과를 반환할 수 있습니다. 이러한 링크는 일반적으로 끊어진 것이 아니라 **확인되지 않은 링크**(으)로 보고됩니다.

## 해결 방법

감사에서 기회가 발견되면 각 단계에서 문제 및 권장 변경 사항을 설명하고 관련 링크를 파악합니다. **페이지에서 강조 표시**&#x200B;를 사용하여 콘텐츠의 링크로 이동한 다음 새 탭에서 URL을 열어 문제를 직접 확인합니다. 끊어진 링크의 경우 페이지의 새 위치로 업데이트하거나 제거합니다. 확인되지 않은 링크의 경우 브라우저에서 링크가 올바로 열렸는지 확인합니다. 영업 기회를 검토하고 해결하는 방법은 [Preflight에서 결과 감사](../../audit-results.md)를 참조하세요.
