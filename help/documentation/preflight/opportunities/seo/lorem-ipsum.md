# Lorem ipsum 감사

**Lorem ipsum** 감사에서 페이지 콘텐츠에 남아 있는 자리 표시자 텍스트를 감지했습니다.

## 왜 중요한가

자리 표시자 텍스트가 있는 페이지를 게시하면 페이지가 읽을 수 없는 것처럼 보입니다. 검색 엔진은 자리 표시자 텍스트를 인덱싱하여 검색 결과에 표시할 수 있고 소셜 플랫폼은 링크 미리보기에 표시할 수 있습니다. 자리 표시자 텍스트는 종종 보기에서 숨겨집니다(예: 이미지 대체 텍스트 또는 접근성 레이블). 이 경우 화면 판독기 또는 기타 보조 기술을 사용하는 사람은 페이지에 표시되지 않더라도 여전히 이 소리를 들을 수 있습니다.

## 감사 확인 사항

감사는 자리 표시자 텍스트가 표시되는 페이지의 각 위치를 보고합니다. 표시된 페이지 텍스트와 일부 위치가 즉시 또는 전혀 표시되지 않을 수 있는지 확인합니다.

* 이미지 대체 텍스트
* 접근성 레이블 및 설명
* 양식 필드 자리 표시자
* 툴팁
* 페이지 제목
* 메타 설명 및 소셜 공유 태그와 같은 메타데이터

스크립트 및 스타일과 같이 사용자에게 표시되지 않는 코드는 검사되지 않습니다.

## 텍스트 일치 방법

감사는 대문자와 소문자를 조합하여 &quot;lorem ipsum&quot; 구문을 찾습니다. 또한 단어들이 줄이나 요소들로 나뉘거나 둘 사이에 공백이 없을 때 그 어구를 찾아냅니다. 구문이 동일한 요소나 속성에 두 번 이상 나타나면 해당 위치가 한 번 보고됩니다.

## 알려진 제한 사항

* **&quot;lorem ipsum&quot;:** &quot;TBD&quot; 또는 &quot;lorem ipsum&quot;이 없는 다른 라틴어 채우기 단어와 같은 다른 자리 표시자 텍스트만 검색되지 않습니다.
* **페이지의 강조 표시:**&#x200B;은(는) 페이지에 표시되지 않으므로 페이지 제목이나 메타데이터에 사용할 수 없습니다. **Details** 및 **Element** 상자를 사용하여 텍스트를 찾습니다.

## 해결 방법

페이지 제목, 대체 텍스트 또는 머리글과 같은 텍스트 위치는 **세부 정보**&#x200B;를 확인하세요. **권장 사항**&#x200B;에서는 수정 방법을 설명하고 **요소** 상자에 태그 안의 텍스트가 표시됩니다.

가능한 경우 **페이지에서 강조 표시**&#x200B;를 사용하십시오. 숨겨진 요소는 다른 화면 크기나 메뉴 또는 대화 상자에 나타날 수 있습니다.

자리 표시자 텍스트를 바꾸거나 제거합니다. 대체 텍스트 및 액세서빌러티 레이블의 경우 이미지 또는 컨트롤을 설명하십시오. 자세한 내용은 [Preflight의 감사 결과](../../audit-results.md)를 참조하십시오.
