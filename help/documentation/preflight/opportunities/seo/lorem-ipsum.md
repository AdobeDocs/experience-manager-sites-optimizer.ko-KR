# Lorem ipsum 감사

**Lorem ipsum** 감사에서 페이지 콘텐츠에 남아 있는 자리 표시자 텍스트를 감지했습니다. 자리 표시자 텍스트가 있는 페이지를 게시하는 것은 독자가 완료하지 않은 것처럼 보이며 검색 엔진으로 인덱싱할 수 있습니다. 감사는 모든 자리 표시자 텍스트에 플래그를 지정하므로 게시하기 전에 실제 콘텐츠로 바꿀 수 있습니다.

감사에서 기회를 찾으면 각 기회는 자리 표시자 텍스트가 표시되는 위치를 식별합니다. 영업 기회를 검토하고 해결하는 방법은 [Preflight에서 결과 감사](../../audit-results.md)를 참조하세요.
