# ASO 문서 에이전트 — 학습 검토

이 에이전트의 자체 PR에 대한 사람 PR 검토 피드백에서 추출된 지속적 레슨입니다. 읽기
`pipeline.md`의 4단계(연구 + 초안) 시작 시 초안을 작성하기 전에 이 파일
어떤 것이든 — 중요한 것은 검토자가 한 번 수정하는 것이
다음 티켓으로 다시 구입했습니다.

## 여기에 속한 항목

**일반화 가능** 피드백만 향후 티켓에 대해 다시 발생하는 패턴입니다.
톤, 구조, 누락된 섹션, 잘못된 파일 배치 또는 컨텐츠 정확도. 예:

- &quot;무시/건너뛰기를 지원하는 기회에 대해 항상 무시됨 탭을 언급하십시오.&quot;
- &quot;티켓이나 기존 형제 페이지에서 확인하지 않는 한 Ultimate 계층 게이팅을 주장하지 마십시오. 주석을 달고 열린 항목으로 플래그를 대신 사용하십시오.&quot;
- &quot;새로운 영업 기회 방법 페이지에는 페이지 자체뿐만 아니라 영업 기회 유형 랜딩 페이지에 TOC.md 항목과 카드 그리드 항목이 필요합니다.&quot;

## 여기에 속하지 않는 사항

단일 PR에만 적용되는 일회성 기계적 피드백: 오타, 끊어진 링크,
특정 PR에 쉼표가 누락되었습니다. 파일 경로가 잘못되었습니다. PR에서 직접 수정 —
미래의 초안으로 일반화하지 마십시오. 따라서 내구성 있는 항목은 노이즈일 뿐입니다.

## 시작 형식

```markdown
## YYYY-MM-DD — SITES-XXXXX (PR #NN)

**Lesson:** [one or two sentences — the generalizable rule]

**Why:** [what the reviewer actually said, or the specific mistake it corrects]

**Applies to:** [which ticket types / pages this affects — "all opportunity how-to pages", "settings/setup pages", "everything", etc.]
```

맨 위에 있는 최신 항목. 이후 단원이 이전 단원을 대체하거나 축소하는 경우 를 편집합니다
이전 항목은 파일에 충돌하는 두 규칙을 남기지 않고 를 확인합니다.
